# Luna the Fox 🦊

Ett charmigt 2D-plattformsspel gjort i **Python** med **Pygame**.

![Luna the Fox](bilder/fullpose.png)

## Om Spelet

**Luna the Fox** är ett mysigt plattformsspel där du styr den söta svarta katten **Luna**. 

Spring, hoppa och utforska olika nivåer medan du samlar mynt och undviker faror!

### Funktioner
- Söta och detaljerade animationer för Luna
- Flera nivåer
- Highscore-system
- Bakgrundsmusik och ljudeffekter
- Spara framsteg
